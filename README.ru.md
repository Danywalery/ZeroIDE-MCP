# ZeroIDE MCP

**Любой AI-агент может управлять твоим Windows-ПК — из чата в браузере, с другого компьютера или откуда угодно ещё, — но только пока ты это разрешаешь.**

ZeroIDE MCP — [MCP](https://modelcontextprotocol.io)-сервер с приложением в трее Windows. Любой AI-клиент с поддержкой MCP (Claude, ChatGPT, Cursor, Codex, Notion и другие) получает инструменты для команд PowerShell и работы с файлами на этом ПК. По умолчанию сервер выключен: ты включаешь его в трее на нужное время, подтверждаешь важные действия и видишь каждый вызов в журнале аудита.

English version: [README.md](README.md)

> **Статус: 0.3.0, первый публичный релиз.** Автотесты проходят в CI, но установка на чистый ПК с каждым AI-клиентом ещё не проверена полностью. См. [Ограничения](#ограничения).

## Зачем это нужно

- **Любой агент, где бы он ни работал.** Веб-чат в браузере (ChatGPT, Claude, Notion или другой с поддержкой MCP), агент для разработки на этом ПК (Claude Code, Cursor, Codex) или агент на другом компьютере — любой из них управляет этим ПК через одни и те же инструменты. Агенту не нужно работать на том компьютере, которым он управляет.
- **Несколько ПК из одного места.** Поставь ZeroIDE MCP на каждый компьютер и добавь каждый в AI-клиент отдельным MCP-сервером. Тогда один агент ведёт одну задачу сразу на нескольких ПК: например, собирает на одном, тестирует на другом и сводит результаты на третьем. Агент, запущенный на одном из твоих ПК, так же управляет остальными.
- **Через свою частную сеть.** Компьютеры в твоей сети [Tailscale](https://tailscale.com) видят друг друга без публичного адреса, поэтому агент на одном ПК ведёт задачу на остальных прямо внутри этой сети. Для облачного AI есть публичный HTTPS-адрес через ngrok, Cloudflare Tunnel или свой сервер.

На каждом ПК свои подтверждения, токены и журнал: токен одного компьютера не подходит к другому.

## Возможности

- **14 инструментов MCP:** команды PowerShell (в том числе фоновые задачи и их вывод), файлы (чтение, запись, правка, список, поиск), статус задачи, сообщения владельцу, скриншоты, журнал аудита и журнал агента.
- **Выключен по умолчанию.** Сервер слушает только 127.0.0.1 и работает, только пока включён в трее. Выключение или выход из трея закрывает доступ через приложение.
- **Подтверждения.** По умолчанию чтение разрешено, а запись и правка файлов и запуск команд ждут твоего подтверждения в трее.
- **Контроль доступа.** Вход через OAuth с подтверждением в трее или именные токены: область доступа (чтение, чтение и запись, полный доступ), папка, из которой токен не выйдет, срок действия и лимит запросов. Токены можно перевыпустить и отозвать.
- **Удалённый доступ на выбор.** Только локально, частная сеть вроде Tailscale, ngrok, Cloudflare Tunnel со своим доменом или свой SSH-сервер. Аккаунты и домены твои, своего шлюза у проекта нет. Подробности — в [CONNECTIONS.md](CONNECTIONS.md) (на английском).
- **Аудит.** Каждый вызов инструмента записывается в журнал, секреты маскируются.

Это **не песочница**: разрешённые команды выполняются с правами твоего пользователя Windows. Считай любое подключение удалённым выполнением кода на ПК и прочитай [SECURITY.md](SECURITY.md).

## Требования

- Windows 10 или 11, x64, PowerShell 5.1 или новее. Права администратора не нужны.
- Интернет во время установки: скачивается переносной Node.js, его SHA-256 сверяется с зашитым значением.
- AI-клиент с поддержкой MCP. Облачным и веб-клиентам нужен доступный HTTPS-адрес, например через ngrok. Агенту на другом твоём ПК хватит частной сети, например Tailscale.

## Установка

1. Открой страницу **Releases** этого репозитория и скачай `zeroide-mcp.zip` (не архивы «Source code»). Хеш можно сверить с `zeroide-mcp.zip.sha256`:
   ```powershell
   Get-FileHash .\zeroide-mcp.zip -Algorithm SHA256
   ```
2. Распакуй архив.
3. Проще всего отдать файл `AGENT_INSTALL.md` из архива своему AI-агенту — он проведёт через установку. Или установи сам из распакованной папки:
   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1
   ```
4. Запусти **ZeroIDE MCP** из меню «Пуск» и включи MCP, когда AI нужен доступ. Подключение для AI-клиента настраивается в трее; подробности для агентов — в [docs/AGENT_CONNECTIONS.md](docs/AGENT_CONNECTIONS.md).

Установщик кладёт всё в `%LOCALAPPDATA%\ZeroIDE-MCP`, не перезаписывает существующую установку, никогда не выводит токены и сам MCP не включает. Он использует локальные порты 39011 и 39012.

## Структура репозитория

| Путь | Что внутри |
|---|---|
| `server/` | MCP-сервер на Node.js (`server.mjs`) и утилита токенов (`tokens-cli.mjs`) |
| `tray/` | Приложение в трее (C#, .NET 8, Windows Forms): запуск и остановка сервера и подключения, подтверждения, доступ, журнал |
| `installer/` | `install.ps1` для релизного пакета |
| `tools/` | Помощники для подключения и первой настройки; их используют установщик и агенты |
| `tests/` | Автотесты; они работают изолированно и не трогают установленную копию |
| `docs/` | Руководство по подключению для агентов, сборка из исходников, заметки к релизу |
| `AGENT_INSTALL.md`, `agent-manifest.json` | Точка входа для AI-агента, который ставит программу из релизного пакета |

## Сборка из исходников

Репозиторий содержит только исходники; релизы собирает GitHub Actions. Как собрать и протестировать локально — в [docs/BUILDING.md](docs/BUILDING.md) (на английском).

## Ограничения

- Релизный пакет и приложение в трее пока без цифровой подписи, поэтому Windows SmartScreen может предупредить.
- Приложение в трее собрано на .NET 8, поддержка которого у Microsoft заканчивается 10 ноября 2026 года. Переход на более новую версию .NET запланирован.
- Ещё не проверено: первая настройка на чистом ПК с каждым AI-клиентом, восстановление после перезагрузки или сбоя, публичный доступ через Cloudflare или Tailscale Funnel.
- Для Tailscale в трее пока нет готового помощника: агент настраивает его вручную по общим шагам подключения из [docs/AGENT_CONNECTIONS.md](docs/AGENT_CONNECTIONS.md). Доступ по адресу внутри сети Tailscale проверялся при разработке.
- Лимиты запросов считаются по адресу клиента, который видит сервер. За туннелем весь удалённый трафик идёт с одного адреса.
